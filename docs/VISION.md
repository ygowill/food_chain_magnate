# 项目愿景

## 目的

本项目以 Godot 4.5 构建《Food Chain Magnate》的非官方数字化实验版本，用于探索确定性桌游引擎、模块化规则、回放/存档、本地对局和在线多人协作流程。

## 成功标准

- 相同初始状态、模块集合与命令序列得到相同结果；
- 基础规则和已声明支持的扩展模块能通过可重复的自动化与人工验证；
- 本地和在线玩家能完成关键对局路径，恢复/回放不产生第二套状态真相；
- 新开发者或 Agent 能在三次跳转内找到能力的意图、决策、代码和验证；
- 当前限制、未验收事项和实验性质保持透明。

## Non-goals

- 不把本项目描述为官方实现或成熟商业产品；
- 不保证所有实体规则和扩展已经完整、无误地实现；
- 不以聊天记录、Agent 自述或本地临时日志替代可审查的项目证物；
- 不为了文档数量、Skill 数量或自动化程度牺牲真相一致性和维护成本。

## 当前阶段

项目处于持续迭代的实验阶段。Architecture、Feature、ADR 和 Validation 是长期知识；过程计划与历史工作日志必须按生命周期归档。
