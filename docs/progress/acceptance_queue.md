## 验收规则

- 验收人必须是 Product Owner、QA 或熟悉该用户路径的人，不能由实现者或 Agent 自行放行。
- 每次验收需记录 Commit、环境、步骤、结果和截图/样例；结果进入对应 Feature 的 Validation，而不是追加到历史 Tracker。
- 验收失败时创建新的稳定 Issue ID，不恢复旧 Tracker 的追加写入模式。
