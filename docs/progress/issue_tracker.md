# Issue 与工作状态入口

旧的追加式 Issue Tracker 已于 2026-07-11 冻结。它混合了需求、诊断、实现、验证和历史状态，不再作为当前事实源。

请按问题类型进入：

- [活跃工作项](../BACKLOG.md)：已经确认要继续推进的工作；
- [待人工验收](acceptance_queue.md)：代码中已有实施记录、但缺少可持久复核的人类验收；
- [历史 Issue Tracker](archive/issue_tracker_2026-07-11.md)：只读原始记录，用于追溯；
- [Feature 聚合页](../features/README.md)：正式能力的意图、决策、实现和验证；
- [Validation](../validation/README.md)：提交级自动/人工验证证物。

禁止继续向历史 Tracker 追加内容。新问题应使用稳定 ID，并进入 Issue 系统或当前 Backlog。
